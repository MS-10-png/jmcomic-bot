# JM Comic Bot 简洁使用说明

## 启动

最推荐直接打开：

```text
JMComicBotManager.exe
```

管理器里可以启动/停止 NoneBot、NapCat，查看日志，管理 QQ 白名单、黑名单和单人功能权限。状态和配置改为手动刷新，需要时点击顶部 `手动刷新`。
也可以点 `清理缓存文件` 删除机器人临时图片、临时压缩包、Python 编译缓存和旧二维码。

如果只想下载漫画到电脑，双击：

```text
启动下载器.bat
```

或运行：

```bash
python main.py 123456
```

下载文件默认保存到 `downloads`。

## 群里怎么用

**群里不用 @ 也可以直接发任务**，@机器人 发同样格式也完全可以，而且不要求标准格式，自然说法都行：

```text
123456 文件 / 帮我下载123456 / 你之前说的350234发我
123456 图片 / 123456 封面 / 把350234打包发群里
123456 详情 / 我的历史 / 最近看过
搜索 关键词 / 随机推荐 / 随机推荐 女仆
分类 / 分类 韩漫 / 分类 韩漫 第2页
jm订阅 123456 / jm取消 123456 / jm订阅列表
签到 / 计算 1+2*3 / 骰子
帮我找找女仆漫画        ← 自然语言任务，AI 识别
```

说明：

- `文件` 会打包成 zip，所有 zip 密码都是漫画编号。
- `图片` 会逐页发送。
- 写 `20页`、`30页` 这类数字时，只处理对应页数。
- 写 `封面` 时只发封面。
- 写 `详情` 会先看简介、作者、章节数再决定下不下。
- 写 `群发` 会发到当前群；写 `私发` 会私发给请求者。
- 搜索写「关键词 第2页」可翻页看更多结果。
- 发「我的历史」查看最近看过的漫画。
- 发「分类」查看分类列表，「分类 韩漫」按分类浏览（加「第2页」翻页）。
- 小鱼刚发完消息后的下一句也会先当任务听：紧接着说「第2页」续翻页、
  「私发/群发」改收发、「文件/图片/封面」改输出、「换一批」重新推荐，不用重复发完整指令。

也可以用斜杠命令：

```text
/jm文件 123456
/jm图片 123456
/jm封面 123456
/jm搜索 关键词
/jm推荐
```

## Pixiv

```text
@机器人 来点图
@机器人 来点图 初音ミク
@机器人 pixiv搜图 初音ミク
@机器人 pid 12345678
满意
不满意
换一张
```

说明：

- `来点图` 会随机抽图。
- `来点图 TAG` 会按 TAG 抽图。
- `满意` 会提高该类 TAG 后续出现概率。
- `不满意` 会降低该类 TAG 后续出现概率。
- `换一张` 会降低上一张概率并重新抽一张。
- R18/R18G 内容需要先发送 `我已满18岁` 完成确认；发送 `取消18认证` 可撤销。
- Pixiv R18/R18G 图片地址通常需要登录 Cookie。若提示需要 Cookie，在 `.env` 里填写 `PIXIV_COOKIE` 或 `PIXIV_PHPSESSID` 后重启 NoneBot；获取方法见《Pixiv登录Cookie获取教程.md》。
- 发 `pixiv登录状态` 可检测当前 Cookie 是否有效。

Pixiv 订阅：

```text
@机器人 pixiv订阅
@机器人 pixiv订阅 群发
@机器人 pixiv取消
@机器人 pixiv状态
```

JM 漫画追更订阅：

```text
@机器人 jm订阅 123456
@机器人 jm订阅 123456 群发   ← 订阅到当前群
@机器人 jm取消 123456
@机器人 jm订阅列表 / 我的订阅
```

说明：

- 订阅某本漫画后，机器人会定期检查（默认 30 分钟，`.env` 里 `JM_SUBSCRIPTION_CHECK_MINUTES` 调整），发现新增章节就推送提醒。
- 斜杠命令同样支持：`/jm订阅 123456`、`/jm取消 123456`、`/jm订阅状态`。

## 管理权限

打开 `JMComicBotManager.exe`：

1. `使用人员`：设置允许 QQ、禁止 QQ、允许群、禁止群。
2. `单个 QQ 功能管理`：输入 QQ 号，单独开关某个人能用的功能。
3. `功能开关`：全局开关功能。
4. `日志`：查看 NoneBot、NapCat、管理器日志。
5. `清理缓存文件`：删除可重新生成的缓存，不删除 `downloads` 里的手动下载漫画。
6. `更新重启 NoneBot`：一键停止并重新启动 NoneBot，加载最新代码，方便调试；改完代码点一下就行（依赖没变不用点"安装/检查依赖"）。

优先级：

```text
禁止名单 > 白名单模式 > 全局功能开关 > 单人功能开关
```

如果一个 QQ 在禁止名单里，单人功能开了也不会放行。

## 维护与缓存（2026-08 更新）

- 机器人临时缓存（`plugins/download` 下的 qq/pixiv 图片）默认自动清理：超过 30 天未使用的文件会被删除，不影响 `downloads` 里的手动下载。想关闭或调整，在 `.env` 里改 `JM_CACHE_MAX_AGE_DAYS`（`0` = 关闭自动清理）。
- 同一本漫画、同样页数的加密 zip 会复用，不会重复打包；图片更新后会自动重新打包。
- JM 域名会在启动时自动刷新。2026-08 修复了域名配置接口的 BOM 兼容问题——旧域名已全部停用，此前搜索/下载会全部失败，现在已恢复正常。
- 界面美化（2026-08）：帮助菜单、搜索结果、随机推荐、Pixiv 卡片都换成了带 emoji 的排版；搜索和随机推荐默认附带封面预览图。不想发封面图，在 `.env` 里把 `JM_SEARCH_SEND_COVERS`、`JM_RECOMMEND_SEND_COVERS` 设为 `0`。

## AI 对话（2026-08 新增）

机器人接入了 DeepSeek AI：**所有 @机器人 的消息会先交给 AI 理解**，AI 识别意图后由机器人执行对应功能并用人设口吻回复。比如：

```text
@机器人 帮我找找女仆漫画        → 自动搜索「女仆」
@机器人 随便推荐几本看看        → 自动随机推荐
@机器人 把 123456 封面发到群里  → 自动识别编号和群发
@机器人 你好呀，你是谁？        → 人设闲聊
@机器人 pid 12345678           → 自动查 Pixiv 图
@机器人 帮我在B站找个猫咪视频  → 自动在 B 站搜索视频
@机器人 破防是什么意思          → 查词解释（词典+联网）
```

说明：

- 配置在 `.env`：`DEEPSEEK_MODEL`（默认 deepseek-chat）、`DEEPSEEK_TIMEOUT` 等；`DEEPSEEK_API_KEY`（必填）请放在 `.env.local`（不纳入版本控制），机器人启动时自动加载，系统环境变量优先级更高。
- AI 人设是「鲸鱼娘 · 小鱼」（DeepSeek 拟人）：软萌吃货、懂技术、会委屈会撒娇，被叫大肥鱼会瘪嘴反驳。人设提示词在 `plugins/llm_chat.py` 的 `SYSTEM_PROMPT`，想微调改那里。
- `DEEPSEEK_API_KEY` 留空 = 关闭 AI，机器人回退到原来的规则解析，所有旧功能不受影响。
- AI 挂了/超时也会自动回退规则解析，不会让机器人哑掉。
- 每个群/私聊会保留最近 `LLM_HISTORY_MAX`（默认 12）条聊天记录用于上下文记忆，2 小时不用自动过期；发「重置记忆」可立即清空。
- 只有 AI 明确拿到数字编号才会触发下载，不会瞎编编号。
- 所有 AI 触发的功能仍然走管理面板的权限配置。
- **联网搜索**：问到新闻、时事、天气、具体事实等需要实时信息的问题时，AI 会先联网搜索（Bing → DuckDuckGo → Baidu 自动切换），再基于结果回答；搜不到的内容会直说不知道，不瞎编。
- **B站视频搜索**：发「b站 关键词 / bilibili 关键词」直接搜，或对 AI 说「帮我找个B站视频」；返回标题、UP主、播放量、时长和视频链接，并附带封面预览（`.env` 里 `JM_BILI_SEND_COVERS` 可调，`0` = 只发文字）。不用登录 Cookie，解析 B 站搜索页。
- **查词解释**：发「XX是什么意思 / XX啥意思 / 解释一下XX」，小鱼会先查词典（英文走 dictionaryapi.dev，中英文都查有道），再联网补充网络流行语/圈内黑话的用法，用 AI 组织成口语化解释；AI 未启用时直接返回词典释义。
- **聊天偏好本地库**：机器人会把每个群/私聊的聊天偏好存在本地 SQLite（`plugins/llm_user_prefs.db`）。不想让小鱼三句不离 token、或不想看动作描写，直接说「少说token」「少点动作描写」；喜欢就反过来说「多来点token梗」「多动作描写」。发「查看偏好」看当前设置；聊得多了如果用户从没提过 token 主题，也会自动减少 token 梗。
- 注意：@机器人的消息会发送给 DeepSeek API 处理，请勿发送敏感信息。

## 预设小技能（@我使用，本地秒回不烧 token）

```text
@机器人 签到                    → 每日签到，记连续天数（本地库）
@机器人 计算 1+2*3              → 计算器（支持 + - * / ^ % 括号）
@机器人 骰子 / 2d20 / d100      → 掷骰子
@机器人 随机数 1 100            → 随机数
@机器人 抽签                    → 今日运势
@机器人 倒计时 2027-1-1         → 距目标日期天数
@机器人 随机点名                → 群里随机 @ 一个人（需要群成员列表权限）
@机器人 讲个笑话 / 夸夸我       → 小娱乐
@机器人 你好 / 谢谢 / 大肥鱼    → 预设应对（问候/感谢/委屈反驳）
@机器人 怎么下载 / 密码是多少   → FAQ 快捷回答
@机器人 帮助                    → 完整菜单
```

更多细节：问候按时间段自动换文案；被打趣/挨骂有随机委屈回应；「更新了什么」会报近期改动摘要。

## 群聊自主聊天（2026-08 新增）

小鱼会在群里看最近的聊天记录，偶尔自然地插句话（纯闲聊，绝不触发功能或发图）：

- **LLM 判断接话（chat_judge，默认开启）**：用 AI 结合群聊上下文判断「这句话是不是在跟小鱼说」——提到小鱼/机器人名字、回应小鱼刚说的话、向小鱼提问使唤（如「来点图」「推荐几本」即使没 @）都会接话；群友之间纯闲聊则保持安静。比旧的概率式接话更聪明，不刷屏。
- **发完消息着重检测下一句**：小鱼刚在群里发过话（默认 90 秒内），用户紧接着的下一句视为回复小鱼，会跳过冷却强制判断，并提示 AI 重点判断（没提名字也会接）。
- **闭嘴机制**：群里有人说「小鱼闭嘴」→ 委屈回一句后安静下来，默认 10 分钟后自动复出；说「小鱼可以说话了/解禁」可提前解除。闭嘴期间 @她 的功能照常可用。
- **进群问候**：被拉进群时自报家门、介绍全部功能（7 天内不重复）。
- 所有行为可在 `.env` 调整：`JM_CHAT_JUDGE`（0=关闭新判断，退回旧的概率接话）、`JM_CHAT_JUDGE_MIN_INTERVAL`、`JM_CHAT_JUDGE_MAX_PER_HOUR`、`JM_CHAT_JUDGE_FOLLOWUP_SECONDS`，以及旧参数 `JM_AUTO_CHAT`、`JM_AUTO_CHAT_PROBABILITY`、`JM_AUTO_CHAT_MIN_INTERVAL`、`JM_AUTO_CHAT_MAX_PER_HOUR`、`JM_SILENCE_SECONDS`。

## 常见问题

- 改了代码或帮助菜单后，需要重启 NoneBot 才生效。
- 管理器不会自动刷新；需要更新状态、配置或日志时，点击顶部 `手动刷新`，或在日志页点击 `刷新日志`。
- OneBot 地址应为：`ws://127.0.0.1:8081/onebot/v11/ws`
- 图片错位/损坏时，程序会自动尝试解码修复后再发送。
- 逐页发送间隔可用 `.env` 里 `JM_SEND_DELAY_SECONDS` 调整（默认 1 秒，`0` = 不等待）；`@机器人` 发数字时默认只发 10 页，可用 `JM_SEND_IMAGE_LIMIT` 调整。
